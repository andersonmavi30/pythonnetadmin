# Dell Networking Automation

Python automation examples for Dell network administration, operations and troubleshooting.

Primary platform focus:

- Dell SmartFabric OS10
- Dell OS9 where applicable
- Dell Enterprise SONiC where applicable

Planned areas:

- Netmiko
- Nornir
- Operational show commands
- Interface and VLAN checks
- Routing verification
- Configuration backups
- Configuration changes
- Troubleshooting workflows

NAPALM examples will only be included when an appropriate driver is selected for the target Dell platform.
