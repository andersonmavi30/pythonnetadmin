# Dell Networking Automation

Python automation examples for Dell network administration, operations and troubleshooting across both legacy and current Dell network operating systems.

Primary platform focus:

- **Dell Networking OS6 (legacy)**
- **Dell Networking OS9 (legacy)**
- **Dell SmartFabric OS10**
- **Dell Enterprise SONiC**

Planned areas:

- Netmiko
- Nornir
- Operational show commands
- Interface and VLAN checks
- Routing verification
- ARP and MAC table inspection
- Neighbor discovery
- Configuration backups
- Configuration changes
- Connectivity validation
- Troubleshooting workflows
- Multi-device execution

The examples will keep platform-specific command differences separated where necessary so OS6, OS9, OS10 and Enterprise SONiC are not treated as if they share the same CLI behavior.

NAPALM examples will only be included when an appropriate driver is selected for the target Dell platform.
